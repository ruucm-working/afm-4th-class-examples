# 실습 6 · 미니 프로젝트

> **목표** 앞의 실습을 전부 엮어 실제 업무 하나를 통째로 자동화한다
> **시간** 25분 · **난이도** ★★★★☆
> **쓰는 파일** `샘플/` 전체

---

## 상황

여러분은 책방오후의 운영 담당자입니다. 월말이 됐고 이 일을 해야 합니다.

> 6월 거래명세서 3장이 흩어져 있다.
> 이걸 정산해서 **월간 매입 보고서 PDF**를 만들고,
> 원본 명세서를 뒤에 붙여서, 대표에게 보낼 **암호 걸린 배포본**을 만들어야 한다.

손으로 하면 40분. 지금부터 한 번에 시킵니다.

---

## 미션 · 한 문장으로 시키기

아래를 **그대로** 복붙하세요. 길지만 이게 실무 프롬프트의 실제 모습입니다.

```
책방오후 6월 매입 정산 보고서를 만들어줘. 순서대로 해줘.

[1] 데이터 추출
샘플/거래명세서/ 의 PDF 3개에서 품목 표를 뽑아
결과물/프로젝트/매입내역.csv 로 저장.
열: 거래처, 거래일자, 품명, 수량, 단가, 금액
소계·부가세·합계 행은 제외.

[2] 보고서 PDF 생성 (A4 2쪽)
결과물/프로젝트/6월-매입보고서.pdf

1쪽:
- 남색 띠 제목 "책방오후 2026년 6월 매입 정산 보고서"
- 작성일 2026-06-30, 작성자 운영팀
- 요약 3줄: 총 매입액(부가세 포함), 거래처 수, 품목 수
- 거래처별 매입액 표 (거래처 / 품목수 / 공급가 / 부가세 / 합계)

2쪽:
- "품목별 상세" 제목
- 전체 품목을 금액 내림차순 표로 (12행)
- 맨 아래 총계 행

한글은 reportlab 내장 CJK 폰트를 쓰고, 숫자는 천 단위 쉼표.

[3] 원본 첨부
보고서 뒤에 거래명세서 3장을 날짜순으로 붙여서
결과물/프로젝트/6월-매입보고서-첨부포함.pdf (총 5쪽)

[4] 배포본
모든 쪽에 '대외비' 반투명 워터마크 + 암호 bookcafe2026
결과물/프로젝트/6월-매입보고서-배포용.pdf

[5] 검증
마지막에 아래를 표로 정리해줘.
- 만든 파일 목록과 각 쪽수
- 총 매입액이 [1]의 CSV 합계와 일치하는지
- 배포본이 암호 없이 안 열리고 암호로는 열리는지
```

---

## 정답 확인

숫자가 이렇게 나와야 맞습니다.

| 항목 | 값 |
|---|---|
| 품목 수 | 12개 |
| 공급가 합계 | 1,023,600원 |
| 부가세 10% | 102,360원 |
| **총 매입액** | **1,125,960원** |

거래처별로는 이렇습니다.

| 거래처 | 품목 수 | 공급가 |
|---|---|---|
| B식자재 마트 | 5 | 527,800원 |
| C인쇄소 | 3 | 335,000원 |
| A문구 유통 | 4 | 160,800원 |

가장 비싼 품목은 **원두 에티오피아 1kg (184,000원)** 입니다.

최종 파일은 5쪽이어야 합니다. (보고서 2쪽 + 명세서 3쪽)

> **숫자가 다르면 [1]단계를 의심하세요.** 소계·부가세·합계 행이
> 데이터에 섞여 들어가면 합계가 두 배 가까이 부풀어 오릅니다.

---

## 잘 안 되면

한 번에 다 시켰는데 중간에 틀어졌다면, **처음부터 다시 시키지 말고** 그 단계만 고치세요.

```
[2]단계 보고서에서 거래처별 표의 부가세가 안 맞아. 공급가의 10%로 다시 계산해줘.
다른 단계는 그대로 두고.
```

Claude는 앞 단계 결과 파일을 그대로 재사용합니다. 이게 파일로 남기며 작업하는 이유입니다.

## 되돌아보기

방금 한 걸 정리하면 이렇습니다.

| 단계 | 쓴 실습 | 도구 |
|---|---|---|
| 표 추출 | 실습 2 | pdfplumber |
| 계산·집계 | — | pandas |
| PDF 생성 | 실습 3 | reportlab (CJK 폰트) |
| 합치기 | 실습 4 | pypdf |
| 워터마크·암호 | 실습 4 | pypdf |
| 검증 | 전부 | pypdf 재확인 |

**여러분은 이 중 어느 것도 직접 고르지 않았습니다.** 무엇을 원하는지만 말했죠.
도구 선택은 스킬 문서가 대신했습니다.

그리고 이 프롬프트는 **파일이 3개든 300개든 그대로 씁니다.**

---

## 이제 진짜 여러분 일로

미니 프로젝트를 마쳤으면 마지막 과제가 남았습니다.

> **여러분의 실제 반복 업무 하나를 골라 같은 구조로 프롬프트를 써보세요.**

이 틀에 맞춰보면 됩니다.

```
[1] 어디서 무슨 데이터를 뽑을지
[2] 어떤 문서를 만들지 (쪽수·항목까지)
[3] 뭘 붙이거나 합칠지
[4] 어떻게 배포할지 (워터마크·암호)
[5] 맞게 됐는지 어떻게 확인할지
```

**[5]를 빼먹지 마세요.** 검증을 시키지 않으면 AI는 "다 했습니다"라고 말합니다.
그게 맞는지는 아무도 안 봤을 뿐이죠.

## 더 해볼 것

1. **매달 자동으로** — 이 프롬프트를 `.claude/skills/`에 나만의 스킬로 저장하기
2. **입력을 늘려서** — 명세서 10장을 넣고 같은 프롬프트가 그대로 도는지 확인
3. **다른 스킬과 엮기** — 보고서를 PDF 대신 Word(`docx` 스킬)나 Excel(`xlsx` 스킬)로

> 1번이 다음 단계입니다. 오늘 만든 프롬프트가 좋다면, 그건 이미 스킬의 초안입니다.
