# 실습 4 · 합치기 · 나누기 · 워터마크 · 암호

> **목표** 기존 PDF의 페이지를 자유롭게 다루고, 배포용으로 가공한다
> **시간** 15분 · **난이도** ★★☆☆☆
> **쓰는 파일** `샘플/거래명세서/` 3개, `샘플/책방오후-상반기-운영보고서.pdf`

---

## 1단계 · 합치기

```
샘플/거래명세서/ 안의 PDF 3개를 파일명 순서대로 합쳐서
결과물/6월-거래명세서-합본.pdf 로 저장해줘.
합친 뒤 총 쪽수와 각 쪽의 거래처명을 출력해줘.
```

**성공 기준** — 3쪽이고 순서가 이래야 합니다.

| 쪽 | 거래처 |
|---|---|
| 1 | A문구 유통 |
| 2 | B식자재 마트 |
| 3 | C인쇄소 |

> **순서를 꼭 지정하세요.** 안 하면 OS가 주는 순서대로 합쳐지는데,
> 그게 항상 여러분이 원하는 순서는 아닙니다.

---

## 2단계 · 나누기

반대로 쪼갭니다.

```
샘플/책방오후-상반기-운영보고서.pdf 를 쪽마다 따로 나눠서
결과물/보고서-쪽분리/ 폴더에 저장해줘.
파일명은 보고서-1쪽.pdf 형식으로 해줘.
```

**성공 기준** — 파일 3개: `보고서-1쪽.pdf`, `보고서-2쪽.pdf`, `보고서-3쪽.pdf`

### 필요한 쪽만 뽑기 (더 자주 씀)

```
샘플/책방오후-상반기-운영보고서.pdf 에서 표가 있는 2쪽만 빼서
결과물/실적표만.pdf 로 저장해줘.
```

---

## 3단계 · 워터마크

배포 전에 "대외비" 같은 표시를 넣는 작업입니다.

```
결과물/6월-거래명세서-합본.pdf 의 모든 쪽에 워터마크를 넣어줘.

- 문구: 대외비
- 45도 기울이고 쪽 가운데
- 빨간색, 반투명 (연하게)
- 크기는 크게

결과물/6월-거래명세서-대외비.pdf 로 저장하고 이미지로 확인시켜줘.
```

**성공 기준** — 원본 표와 숫자가 **그대로 읽히면서** 그 위에 연한 빨강 글씨가 겹쳐 보입니다.

> 워터마크가 너무 진해서 내용이 안 보이면
> `워터마크를 더 연하게, alpha 0.1로 해줘`라고 하세요.

### 어떻게 되는 건가

워터마크는 지우개가 아니라 **겹치기**입니다.

1. 워터마크 글자만 있는 빈 PDF를 새로 만든다
2. 원본의 각 쪽에 그걸 겹쳐 얹는다 (`page.merge_page(watermark)`)

그래서 **워터마크는 지울 수 있습니다.** 진짜로 가려야 하는 정보라면
워터마크가 아니라 검게 덮어씌우는 작업(redaction)이 필요합니다.

---

## 4단계 · 암호 걸기

```
결과물/6월-거래명세서-대외비.pdf 에 열기 암호를 걸어줘.
암호는 bookcafe2026 으로 하고
결과물/6월-거래명세서-최종.pdf 로 저장해줘.

저장한 뒤, 암호 없이 열리는지 / 암호로 열리는지 둘 다 확인해줘.
```

**성공 기준** — 이렇게 나와야 합니다.

```
암호 없이 열기: 실패 (암호 필요)
bookcafe2026로 열기: 성공 - 1쪽 첫 줄 "거 래 명 세 서"
```

크롬으로 직접 열어보세요. 암호를 묻습니다.

---

## 5단계 · 한 번에 연결하기 (이게 핵심)

지금까지는 한 단계씩 했죠. 실무에선 **한 문장으로** 시킵니다.

```
샘플/거래명세서/ 의 PDF 3개를 날짜순으로 합치고,
모든 쪽에 '대외비' 반투명 워터마크를 넣고,
암호 bookcafe2026 을 걸어서
결과물/6월-매입자료-배포용.pdf 로 저장해줘.

마지막에 쪽수 / 워터마크 여부 / 암호 여부를 표로 정리해줘.
```

**이게 스킬의 진짜 값어치입니다.** 사람이 손으로 하면 프로그램 3개를 오가며
10분 걸릴 일이 한 문장으로 끝납니다. 파일이 300개여도 같은 문장입니다.

---

## 치트시트

| 작업 | 이렇게 말하세요 |
|---|---|
| 순서 바꾸기 | `3쪽을 맨 앞으로 옮겨줘` |
| 쪽 빼기 | `2쪽을 삭제하고 저장해줘` |
| 회전 | `모든 쪽을 시계방향 90도 돌려줘` |
| 쪽번호 넣기 | `각 쪽 하단 가운데에 "3 / 12" 형식으로 쪽번호를 넣어줘` |
| 암호 풀기 | `암호 abcd로 열어서 암호 없는 버전으로 저장해줘` |
| 용량 줄이기 | `이미지 화질을 낮춰서 파일 크기를 줄여줘` |

> **암호 풀기는 내가 아는 암호에만 씁니다.** 남의 문서 암호를 푸는 도구가 아닙니다.
