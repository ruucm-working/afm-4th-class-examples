# 실습 2 · 표 뽑아서 엑셀로

> **목표** PDF 안의 표를 데이터로 뽑아내고, 여러 파일을 한 번에 처리한다
> **시간** 15분 · **난이도** ★★☆☆☆
> **쓰는 파일** `샘플/책방오후-상반기-운영보고서.pdf`, `샘플/거래명세서/` 3개

---

## 왜 이게 중요한가

PDF의 표는 **그림이 아니라 글자인데 줄이 안 맞습니다.** 복사해서 엑셀에 붙이면
한 열로 뭉개지죠. 이 실습은 그 문제를 없애는 겁니다.

---

## 1단계 · 표 하나 뽑기

```
샘플/책방오후-상반기-운영보고서.pdf 의 2쪽에 있는 표 2개를 뽑아서
결과물/책방오후-실적.xlsx 로 저장해줘.
시트는 표마다 따로 만들고, 시트 이름은 표 제목을 써줘.
```

**성공 기준** — 엑셀을 열면 시트 2개가 있어야 합니다.

| 시트 | 내용 |
|---|---|
| 월별 실적 | 월 / 매출 / 방문객 / 객단가 / 신규회원 · 6행 |
| 부문별 매출 | 부문 / 상반기 매출 / 비중 / 전년 대비 · 4행 |

숫자가 `1,180`처럼 **문자로** 들어가 있을 겁니다. 계산하려면 숫자여야 하죠.

```
매출·방문객·객단가·신규회원 열의 쉼표를 없애고 숫자 타입으로 바꿔줘.
그리고 매출 합계를 맨 아래에 추가해줘.
```

합계가 **8,420**(만 원)으로 나오면 정확합니다. 보고서 1쪽 요약의 총매출과 일치하죠.

---

## 2단계 · 여러 파일을 한 번에 (핵심)

여기서부터가 진짜입니다. 거래명세서 3장을 **한 개의 표로** 합칩니다.

```
샘플/거래명세서/ 안의 PDF 3개에서 품목 표를 전부 뽑아서
결과물/6월-매입내역.csv 로 합쳐줘.

열은 이렇게 만들어줘: 거래처, 거래일자, 품명, 수량, 단가, 금액
- 거래처와 거래일자는 각 PDF 상단에서 읽어와줘
- 소계·부가세·합계 행은 빼줘
- 금액 기준 내림차순으로 정렬해줘
```

**성공 기준** — 12행이 나옵니다. (A문구 4 + B식자재 5 + C인쇄소 3)

금액 내림차순이니 맨 윗줄은 이래야 합니다.

```
B식자재 마트, 2026-06-12, 원두 에티오피아 1kg, 8, 23000, 184000
```

> **왜 12행인가?** 소계·부가세·합계를 빼라고 했기 때문입니다.
> 이 지시를 빼면 21행이 나오면서 데이터가 오염됩니다.
> **"뭘 빼야 하는지"를 말해주는 게 표 추출의 절반입니다.**

---

## 3단계 · 뽑은 데이터로 분석시키기

CSV까지 나왔으면 이제 그냥 데이터입니다.

```
결과물/6월-매입내역.csv 를 보고 알려줘.
1. 거래처별 총 매입액
2. 가장 비싼 품목 3개
3. 6월 총 매입액 (부가세 별도)
```

**정답 확인용** (모두 부가세 별도 공급가)

| 거래처 | 품목 수 | 매입액 |
|---|---|---|
| B식자재 마트 | 5 | 527,800원 |
| C인쇄소 | 3 | 335,000원 |
| A문구 유통 | 4 | 160,800원 |
| **합계** | **12** | **1,023,600원** |

가장 비싼 품목 3개는 원두 에티오피아 1kg(184,000) · 멤버십 카드 인쇄(155,000) ·
우유 1L(144,000) 입니다.

숫자가 다르면 2단계 CSV에 소계 행이 섞여 들어간 겁니다.

## 막히면

### `ModuleNotFoundError: No module named 'pdfplumber'`

표 추출은 `pdfplumber`라는 라이브러리가 제일 잘합니다. 없으면 이렇게 말하세요.

```
pdfplumber가 없대. 전역 설치 말고 uv로 임시 환경에서 실행해줘
```

`uv run --with pdfplumber python ...` 형태로 **아무것도 설치하지 않고** 돌아갑니다.
직접 깔고 싶으면 `pip install pdfplumber`.

### 표가 이상하게 쪼개져 나옴

`pdfplumber`가 선(罫線)을 못 찾은 경우입니다.

```
표 경계를 선이 아니라 글자 위치 기준으로 인식해서 다시 뽑아줘
```

## 무슨 일이 일어난 건가

스킬의 `SKILL.md`에는 이런 표가 들어 있습니다.

| Task | Best Tool |
|---|---|
| Extract text | pdfplumber |
| **Extract tables** | **pdfplumber** `page.extract_tables()` |
| Create PDFs | reportlab |

Claude는 "표"라는 단어를 보고 이 표에서 **pdfplumber를 골랐습니다.**
`pypdf`로도 글자는 뽑히지만 표 구조는 무너집니다. 스킬이 없었다면
Claude가 아무거나 골라 절반쯤 성공했을 겁니다.

**스킬의 가치는 "할 수 있게 만드는 것"보다 "매번 같은 방법으로 하게 만드는 것"에 있습니다.**

## 응용 과제

1. **엑셀 서식까지** — "헤더를 굵게, 금액 열은 천 단위 쉼표, 열 너비 자동 맞춤"
2. **피벗 만들기** — 거래처 × 품목 카테고리 교차표
3. **내 PDF로** — 은행 거래내역서나 카드 명세서 PDF를 넣고 CSV로 뽑기
