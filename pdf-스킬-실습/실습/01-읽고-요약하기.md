# 실습 1 · PDF 읽고 요약하기

> **목표** PDF에서 글자를 뽑아내고, 내용을 요약·검색시킨다
> **시간** 10분 · **난이도** ★☆☆☆☆
> **쓰는 파일** `샘플/책방오후-상반기-운영보고서.pdf` (3쪽)

---

## 1단계 · 일단 열어보기

Claude에게 그대로 복붙하세요.

```
샘플/책방오후-상반기-운영보고서.pdf 가 몇 쪽인지,
제목과 작성자가 뭔지 알려줘.
```

**이렇게 나오면 성공**

```
페이지 수: 3
제목: 책방오후 2026년 상반기 운영 보고서
작성자: 책방오후 운영팀
```

제목과 작성자는 본문이 아니라 PDF **메타데이터**에서 나온 값입니다.
파일 속성에 숨어 있는 정보죠.

---

## 2단계 · 요약시키기

```
샘플/책방오후-상반기-운영보고서.pdf 를 읽고
경영진에게 보고할 3줄 요약을 만들어줘. 숫자는 꼭 포함해줘.
```

**이런 내용이 나와야 합니다**

- 상반기 총매출 8,420만 원, 전년 대비 18.6% 성장
- 성장의 대부분은 1월 시작한 멤버십(회원 214명)에서 발생
- 음료 매출은 2.4% 감소 — 4월 가격 인상이 방문객 감소를 못 메움

숫자가 안 나오거나 뭉뚱그려지면 "숫자를 꼭 넣어줘"를 다시 강조하세요.

---

## 3단계 · 특정 정보 찾기 (진짜 실전)

요약보다 훨씬 자주 쓰는 기능입니다.

```
샘플/책방오후-상반기-운영보고서.pdf 에서
4월에 무슨 일이 있었는지, 몇 쪽에 나오는지 찾아줘.
```

**성공 기준** — 2쪽이라고 답하면서, 이 내용을 짚어야 합니다.

> 4월은 방문객이 3월보다 78명 줄었는데 매출은 115만 원 늘었다.
> 4월 1일 음료 가격을 평균 12% 올린 효과.

**쪽수까지 물어보는 게 포인트입니다.** 원문을 직접 확인할 수 있어야
AI 답변을 믿을 수 있습니다. 200쪽짜리 계약서에서 이 습관이 여러분을 살립니다.

---

## 4단계 · 눈으로 확인하기

글자만 뽑으면 **표나 그림의 배치**는 알 수 없습니다. 이럴 땐 이미지로 봅니다.

```
샘플/책방오후-상반기-운영보고서.pdf 의 2쪽을 이미지로 변환해서 보여줘.
```

> Windows에서 `poppler가 없다`는 오류가 나면
> `poppler 없이 pypdfium2로 변환해줘`라고 말하세요.

Claude가 이미지를 직접 보고 "표가 2개 있고, 위쪽은 월별 실적, 아래쪽은 부문별 매출"
처럼 **레이아웃까지** 이해합니다. 스캔한 문서나 복잡한 서식에서 특히 유용합니다.

---

## 무슨 일이 일어난 건가

Claude가 `PDF`라는 단어를 보는 순간 `.claude/skills/pdf/SKILL.md`를 펼칩니다.
거기 이렇게 적혀 있습니다.

```python
from pypdf import PdfReader
reader = PdfReader("document.pdf")
text = ""
for page in reader.pages:
    text += page.extract_text()
```

Claude는 이 코드를 그대로 가져와 파일 경로만 바꿔 실행합니다.
**어떤 라이브러리를 쓸지 고민하는 단계가 통째로 사라진 것**, 이게 스킬의 효과입니다.

## 응용 과제

직접 프롬프트를 만들어보세요. 정답은 없습니다.

1. **위험 요인 3개를 표로** — 보고서 3쪽에 있는 위험 요인을 표로 정리시키기
