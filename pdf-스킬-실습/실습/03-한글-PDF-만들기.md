# 실습 3 · 한글 PDF 만들기

> **목표** PDF를 처음부터 만들고, 한글 깨짐 문제를 정면으로 겪고 해결한다
> **시간** 15분 · **난이도** ★★☆☆☆
> **쓰는 파일** 없음 (새로 만듭니다)

---

## 이 실습의 진짜 목적

**한글 PDF 만들기는 거의 항상 한 번은 실패합니다.** 글자가 `□□□`로 나오죠.
이건 여러분 실수가 아니라 PDF 기본 폰트에 한글이 없어서입니다.

이 실습은 그 실패를 **일부러 겪어보고** 해결법을 손에 익히는 시간입니다.
넘어가지 마세요. 실무에서 반드시 만납니다.

---

## 1단계 · 일단 만들어보기

```
아래 내용으로 A4 한 쪽짜리 PDF를 만들어서
결과물/독서모임-안내문.pdf 로 저장해줘.

제목: 책방오후 9월 독서모임 안내
본문:
- 일시: 2026년 9월 12일 (토) 오후 2시
- 장소: 책방오후 2층
- 이달의 책: 「아무튼, 계속」
- 참가비: 5,000원 (음료 포함)
- 신청: hello@example.com

만든 다음 PDF를 이미지로 변환해서 한글이 제대로 나왔는지 보여줘.
```

마지막 줄이 중요합니다. **이미지로 확인시키지 않으면 깨진 걸 모릅니다.**

---

## 2단계 · 깨졌다면 (아마 깨졌을 겁니다)

글자 자리에 검은 네모가 보이면 이렇게 말하세요.

```
한글이 네모로 깨져. reportlab 내장 CJK 폰트를 써서 다시 만들어줘.
```

**해결 코드는 이렇습니다** — Claude가 이걸 씁니다.

```python
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.cidfonts import UnicodeCIDFont

pdfmetrics.registerFont(UnicodeCIDFont('HYSMyeongJo-Medium'))  # 명조
pdfmetrics.registerFont(UnicodeCIDFont('HYGothic-Medium'))     # 고딕

c.setFont('HYGothic-Medium', 14)
c.drawString(60, 760, "한글이 잘 나옵니다")
```

### 왜 이게 최선인가

한글 폰트 해결법은 두 가지인데, 차이가 큽니다.

| 방법 | 폰트 파일 | 파일 크기 | 다른 PC에서 |
|---|---|---|---|
| **내장 CJK 폰트** (권장) | 필요 없음 | 2KB | 어디서나 OK |
| TTF 임베딩 (나눔고딕 등) | 다운로드 필요 | 30KB~ | OK |

인터넷 글 대부분은 "나눔고딕을 다운받아 등록하라"고 합니다.
하지만 reportlab에는 **한국어 폰트가 이미 들어 있습니다.** 받을 필요가 없어요.

쓸 수 있는 이름은 `HYSMyeongJo-Medium`(명조), `HYGothic-Medium`(고딕) 두 개입니다.

---

## 3단계 · 제대로 된 문서로 만들기

이제 표와 서식을 넣습니다.

```
결과물/독서모임-안내문.pdf 를 다시 만들어줘. 이번엔 이렇게:

- 맨 위에 짙은 남색 띠, 그 위에 흰 글씨로 제목
- 안내 항목은 2열 표로 (왼쪽 항목명 회색 배경, 오른쪽 내용)
- 표 아래에 이달의 책 소개 3줄
- 맨 아래 회색 작은 글씨로 문의처

한글 폰트는 내장 CJK 폰트를 쓰고, 다 만든 뒤 이미지로 보여줘.
```

**성공 기준**

- 제목이 흰 글씨로 남색 띠 위에 있음
- 표 테두리와 배경색이 보임
- 한글이 하나도 안 깨짐

## 4단계 · 텍스트가 살아있는지 확인

**중요합니다.** 보기에 멀쩡해도 글자가 "그림"으로 들어가면 검색·복사가 안 됩니다.

```
결과물/독서모임-안내문.pdf 에서 텍스트를 추출해서 출력해줘.
```

**한글이 그대로 나와야 합니다.**

```
책방오후 9월 독서모임 안내
일시  2026년 9월 12일 (토) 오후 2시
장소  책방오후 2층
...
```

`(cid:12)(cid:34)` 같은 게 나오면 폰트 등록이 잘못된 겁니다.
**"만들었다"와 "제대로 만들었다"는 다릅니다.** 이 확인 습관을 들이세요.

## 알아두면 좋은 함정

스킬의 `SKILL.md`에 이렇게 대문자로 경고돼 있습니다.

> **IMPORTANT**: Never use Unicode subscript/superscript characters (₀₁₂₃, ⁰¹²³)
> in ReportLab PDFs. The built-in fonts do not include these glyphs,
> causing them to render as solid black boxes.

`H₂O`나 `x²`를 그냥 쓰면 검은 네모가 됩니다. 대신 태그를 씁니다.

```python
Paragraph("H<sub>2</sub>O", styles['Normal'])
Paragraph("x<super>2</super>", styles['Normal'])
```

**이런 게 스킬에 적혀 있는 이유** — Anthropic이 실제로 겪은 실패를 문서로
박아둔 겁니다. 스킬은 "잘하는 법"보다 **"이렇게 하면 망한다"를 적어두는 게
더 값어치가 큽니다.** 여러분이 스킬을 만들 때도 똑같습니다.
