# 실습 5 · 양식 자동 채우기

> **목표** 빈 신청서 PDF의 입력칸을 프로그램으로 채운다
> **시간** 20분 · **난이도** ★★★☆☆
> **쓰는 파일** `샘플/수강신청서-빈양식.pdf` (입력칸 11개)

---

## 이게 왜 스킬의 진짜 무기인가

앞의 실습 1~4는 스킬이 없어도 Claude가 웬만큼 합니다. 하지만 양식 채우기는 다릅니다.

PDF 양식에는 두 종류가 있습니다.

| 종류 | 정체 | 채우는 법 |
|---|---|---|
| **채울 수 있는 양식** | 입력칸이 데이터로 들어있음 | 칸 이름에 값을 넣는다 |
| **못 채우는 양식** | 그냥 선이 그려진 그림 | 좌표를 계산해 글자를 얹는다 |

**둘은 방법이 완전히 다릅니다.** 스킬은 `forms.md`(294줄)에 이 분기와
검증된 스크립트 4개를 담아뒀습니다. 그래서 Claude가 헤매지 않습니다.

---

## 1단계 · 어떤 양식인지 판별하기

가장 먼저 할 일입니다. 건너뛰면 엉뚱한 방법으로 갑니다.

```
샘플/수강신청서-빈양식.pdf 가 채울 수 있는 양식인지 확인하고,
입력칸이 몇 개 있는지, 각각 어떤 종류인지 알려줘.
```

**성공 기준** — 입력칸 11개가 이렇게 나옵니다.

| 칸 이름 | 종류 | 넣을 수 있는 값 |
|---|---|---|
| 이름 · 이메일 · 연락처 · 소속 | 글자 | 아무 문자열 |
| 관심_AI활용 · 관심_자동화 · 관심_문서작업 | 체크박스 | `/Yes` 또는 `/Off` |
| 사용경험 | 라디오 (택1) | `/none` `/some` `/often` |
| 신청동기 | 글자 (여러 줄) | 아무 문자열 |
| 개인정보동의 | 체크박스 | `/Yes` 또는 `/Off` |
| 신청일 | 글자 | 날짜 문자열 |

> **`/Yes`의 슬래시는 오타가 아닙니다.** PDF 내부에서 체크박스 값은
> `/Yes` 같은 이름(Name) 객체로 저장됩니다. 그냥 `Yes`를 넣으면 안 먹습니다.

---

## 2단계 · 채우기

```
샘플/수강신청서-빈양식.pdf 를 아래 값으로 채워서
결과물/수강신청서-김수강.pdf 로 저장해줘.

이름: 김수강
이메일: sugang@example.com
연락처: 010-1234-5678
소속: 책방오후
관심 분야: AI 활용, 반복업무 자동화 (문서작업은 체크 안 함)
AI 사용 경험: 조금 써봤다
신청 동기: 반복되는 문서 작업을 줄이고 싶습니다.
개인정보 동의: 체크
신청일: 2026-08-29

다 채운 뒤 이미지로 변환해서 보여줘.
```

**성공 기준** — 이미지에서 확인하세요.

- 한글 이름 "김수강"과 소속 "책방오후"가 안 깨지고 보임
- 체크박스 2개에 ✓, 세 번째는 빈칸
- 라디오는 "조금 써봤다"만 채워짐
- 신청 동기가 여러 줄 상자 안에 있음

---

## 3단계 · Windows 한글 오류 만나기

2단계에서 이런 오류가 나올 수 있습니다.

```
UnicodeDecodeError: 'charmap' codec can't decode byte 0x9d
```

**당황하지 마세요. 여러분 잘못이 아닙니다.**

스킬에 들어있는 `fill_fillable_fields.py`가 JSON 파일을 열 때
인코딩을 지정하지 않았습니다. 영어권에선 문제가 없지만
**Windows 한국어 환경(cp949)에서는 한글 값이 들어가는 순간 깨집니다.**

해결책은 한 줄입니다.

```
PYTHONUTF8=1 을 붙여서 다시 실행해줘
```

이 환경변수는 파이썬이 파일을 읽고 쓸 때 무조건 UTF-8을 쓰게 만듭니다.

> **이게 오늘 수업에서 제일 값진 순간일지도 모릅니다.**
> Anthropic이 만든 공식 스킬도 한국어 환경에선 완벽하지 않습니다.
> 남이 만든 도구를 쓸 때 **어디가 깨질지 알고, 왜 깨지는지 설명할 수 있는 것** —
> 그게 AI 도구를 쓰는 사람과 휘둘리는 사람의 차이입니다.

---

## 4단계 · 여러 명 한 번에 (실무 패턴)

여기서부터가 자동화입니다.

```
샘플/수강신청서-빈양식.pdf 를 아래 3명 것으로 각각 채워서
결과물/신청서/ 폴더에 저장해줘. 파일명은 수강신청서-이름.pdf 형식으로.

1. 박서준 / seojun@example.com / 010-2222-3333 / 카페모아
   관심: 반복업무 자동화 / 경험: 처음이다
   동기: 매일 하는 정산 작업을 자동화하고 싶습니다.

2. 이하늘 / haneul@example.com / 010-4444-5555 / 하늘문구
   관심: AI 활용, 문서 작업 / 경험: 자주 쓴다
   동기: 팀에 AI 사용법을 전파하는 역할을 맡았습니다.

3. 최민서 / minseo@example.com / 010-6666-7777 / 프리랜서
   관심: AI 활용, 반복업무 자동화, 문서 작업 / 경험: 조금 써봤다
   동기: 제안서 작성 시간을 절반으로 줄이고 싶습니다.

전원 개인정보 동의 체크, 신청일은 2026-08-29.
다 만든 뒤 3장을 하나로 합쳐서 결과물/신청서-전체.pdf 도 만들어줘.
```

**성공 기준** — 개별 3개 + 합본 1개(3쪽). 이름별로 체크 상태가 다릅니다.

**엑셀 명단 100명이 있어도 프롬프트는 똑같습니다.**
"CSV 읽어서 전원 것 만들어줘" 한 줄이면 됩니다.

---

## 못 채우는 양식이라면

스캔한 종이 신청서처럼 입력칸이 없는 PDF도 많습니다. 그럴 땐 이렇게 말하세요.

```
이 PDF는 채울 수 있는 양식이 아니야.
쪽을 이미지로 보고 각 칸 위치를 찾아서 글자를 얹는 방식으로 채워줘.
채운 뒤 이미지로 확인시켜줘.
```

Claude가 `forms.md`의 다른 절차를 따릅니다.

1. 쪽을 이미지로 변환
2. 이미지를 **직접 보고** 빈칸 좌표를 추정
3. 그 위치에 글자를 그림
4. 결과 이미지로 검증

느리고 덜 정확합니다. **원본이 채울 수 있는 양식인지 먼저 확인하는 게
1단계인 이유**가 이겁니다.

---

## 응용 과제

1. **직접 만든 양식으로** — 실습 3 방식으로 빈 양식 PDF를 만들고 그걸 채워보기
2. **읽어내기** — 채운 신청서에서 값만 뽑아 CSV로 되돌리기 (제출 취합 자동화)
3. **내 서류로** — 실제 신청서·계약서 PDF를 넣고 채워보기

> 2번이 실무에서 강력합니다. 신청서 50장 → 명단 엑셀 1장이 몇 초입니다.
