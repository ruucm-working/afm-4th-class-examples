# PDF 스킬 실습

Claude 공식 **PDF 스킬**로 문서 작업을 자동화하는 6개 실습입니다.

이 실습에서 여러분이 쓰는 건 **파이썬 코드가 아니라 프롬프트**입니다.
"이 PDF에서 표 뽑아서 엑셀로 만들어줘"라고 말하면, Claude가 스킬 설명서를 읽고
알아서 코드를 짜서 실행합니다. 우리가 배우는 건 **어떻게 말해야 잘 알아듣는가**입니다.

---

## 0. 준비 (3분)

### 필요한 것

| 항목 | 확인 방법 | 없으면 |
|---|---|---|
| Claude Code | 이 창이 켜져 있으면 OK | — |
| Python 3.9+ | `python --version` | [python.org](https://www.python.org/downloads/) |
| PDF 뷰어 | 크롬으로 열면 됨 | — |

### 진짜 준비됐는지 한 번에 확인

Claude에게 그대로 복붙하세요.

```
pdf-스킬-실습 폴더의 샘플 PDF들이 정상인지 확인해줘.
각 파일의 쪽수와 첫 줄을 출력해줘.
```

쪽수가 나오면 준비 끝입니다.

> **Windows 한글 사용자 주의**
> 파이썬이 한글을 출력할 때 `UnicodeDecodeError`가 날 수 있습니다.
> 이건 여러분 잘못이 아니라 Windows 기본 인코딩(cp949) 때문입니다.
> Claude가 알아서 `PYTHONUTF8=1`을 붙여 해결하지만, 직접 돌릴 땐 이렇게 하세요.
> ```
> PYTHONUTF8=1 python 스크립트.py
> ```

## 1. PDF 스킬이 뭔가요

**스킬 = Claude에게 주는 "그 분야 사용설명서 폴더"** 입니다.

Claude는 원래도 PDF를 다룰 줄 압니다. 하지만 매번 "어떤 라이브러리를 쓸까,
표는 어떻게 뽑을까"를 처음부터 고민합니다. 스킬은 그 고민의 답을 미리 적어둔
문서 뭉치입니다. Claude는 PDF 얘기가 나오는 순간 이 폴더를 펴 봅니다.

실제로 이 저장소의 `.claude/skills/pdf/` 안에는 이런 게 들어 있습니다.

| 파일 | 분량 | 언제 읽히나 |
|---|---|---|
| `SKILL.md` | 314줄 | PDF 얘기가 나오면 **항상** |
| `forms.md` | 294줄 | 양식(form) 채울 때**만** |
| `reference.md` | 611줄 | 어려운 작업일 때**만** |
| `scripts/*.py` | 8개 | 양식 작업용 검증된 스크립트 |

### 왜 이렇게 쪼개놨을까

이게 스킬 설계의 핵심입니다. 1,200줄을 통째로 읽히면 Claude의 기억 공간이
낭비됩니다. 그래서 **평소엔 314줄만, 양식 작업일 때만 294줄을 더** 읽습니다.
필요한 만큼만 펼쳐 보는 방식(progressive disclosure)이죠.

여러분이 나중에 직접 스킬을 만들 때도 똑같이 하면 됩니다.

### 스킬 부르는 법

그냥 **PDF 얘기를 하면 자동으로** 켜집니다. 확실히 하고 싶으면 이렇게 쓰세요.

```
PDF 스킬 써서 ○○ 해줘
```

### 다른 프로젝트에서도 쓰려면

이 저장소에는 이미 들어 있지만, 다른 폴더에서 쓰려면 Claude Code에 설치하세요.

```
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
```

PDF 말고도 Word(docx), Excel(xlsx), PowerPoint(pptx) 스킬이 같이 들어옵니다.
공식 저장소: <https://github.com/anthropics/skills>

## 3. 샘플 파일

`샘플/` 폴더에 실습용 PDF 5개가 들어 있습니다. 전부 가상의 동네 책방 자료입니다.

```
샘플/
├── 책방오후-상반기-운영보고서.pdf    3쪽, 표 2개  ← 실습 1·2·4
├── 거래명세서/
│   ├── 2026-06_A문구.pdf            품목 4줄     ← 실습 2·4·6
│   ├── 2026-06_B식자재.pdf          품목 5줄
│   └── 2026-06_C인쇄소.pdf          품목 3줄
├── 수강신청서-빈양식.pdf             입력칸 11개  ← 실습 5
└── _샘플-다시만들기.py               (강사용) 샘플 재생성 스크립트
```

수강생은 `_샘플-다시만들기.py`를 실행할 필요가 없습니다.

## 4. 프롬프트 잘 쓰는 3가지 규칙

실습하면서 이 3가지만 기억하세요.

### 규칙 1. 입력과 출력을 **경로로** 못박기

| ❌ 이러지 말고 | ✅ 이렇게 |
|---|---|
| "PDF 좀 합쳐줘" | "`샘플/거래명세서/` 안의 PDF를 날짜순으로 합쳐서 `결과물/6월-거래명세서-합본.pdf`로 저장해줘" |

Claude가 어떤 파일인지 되묻는 왕복이 사라집니다.

### 규칙 2. 결과물의 **모양**을 미리 말하기

| ❌ | ✅ |
|---|---|
| "표 뽑아줘" | "표를 뽑아서 `파일명, 품명, 수량, 단가, 금액` 열을 가진 CSV로 만들어줘" |

열 이름까지 정해주면 한 번에 원하는 게 나옵니다.

### 규칙 3. 검증을 **같이** 시키기

```
...만들고 나서, 만든 PDF를 다시 열어서 쪽수와 첫 줄을 출력해줘.
```

한 문장 붙이는 것만으로 "만들었습니다"하고 끝나는 대신
실제로 열리는지 확인까지 합니다. **실습 내내 이걸 붙이는 습관을 들이세요.**

| 특정 정보 찾기 | `○○.pdf에서 4월 매출이 얼마인지, 몇 쪽에 있는지 알려줘` |

## 6. 자주 막히는 곳

수업 중 실제로 자주 나오는 문제들입니다. **대부분 Claude에게 그대로 붙여넣으면 해결됩니다.**

### `ModuleNotFoundError: No module named 'pdfplumber'`

표 추출에 쓰는 라이브러리가 없습니다. 두 가지 방법이 있습니다.

```
# 방법 1 — 그냥 Claude에게 맡기기 (권장)
pdfplumber가 없다는데, 전역 설치 말고 uv로 임시 환경에서 실행해줘

# 방법 2 — 직접 설치
pip install pdfplumber
```

`uv`가 깔려 있으면 `uv run --with pdfplumber python ...`으로 **설치 없이** 돌아갑니다.

### `UnicodeDecodeError` / `UnicodeEncodeError`

Windows 한글 환경의 기본 인코딩(cp949) 문제입니다. 스킬에 포함된 스크립트조차
이 문제를 만납니다. 명령 앞에 `PYTHONUTF8=1`을 붙이면 해결됩니다.

### PDF 글자가 □□□ 로 나옴

한글 폰트를 지정하지 않고 PDF를 만든 경우입니다. **실습 3**에서 자세히 다룹니다.
급하면 이렇게 말하세요.

```
한글이 네모로 깨져. reportlab 내장 CJK 폰트로 다시 만들어줘
```

### `Unable to get page count. Is poppler installed?`

PDF를 이미지로 바꾸는 도구(poppler)가 Windows엔 기본으로 없습니다.
설치할 필요 없이 이렇게 말하세요.

```
poppler 없이 pypdfium2로 이미지 변환해줘
```

### Claude가 스킬을 안 쓰는 것 같음

프롬프트에 "PDF 스킬 써서"를 명시적으로 붙이세요. 그래도 안 되면
`/context`로 스킬이 로드됐는지 확인합니다.
