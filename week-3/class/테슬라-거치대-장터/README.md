## ⚠️ 구매 전 확인사항

- 세 건 모두 게시판상 **"판매(안전)"** 상태로 표시되어 있으나, 1위(2026.07.23)와 3위(2026.06.21)는 등록일이 6~7월이라 **이미 거래가 끝났을 수 있음**. 구매 전 판매자에게 판매 여부 확인 필요.
- 모든 픽은 네이버 **플리마켓 안전거래** 상품 → 구매확정까지 네이버페이가 결제금을 보관.
- 표시 가격에 **구매자 보호 수수료(2.2%)** 가 별도로 붙음.
- 거치대는 차종별 호환이 갈리므로(모델3/Y 주니퍼 vs 모델X) 본인 차량과 맞는지 확인할 것.
