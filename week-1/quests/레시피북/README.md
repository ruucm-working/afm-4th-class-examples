# 15분 레시피북

퇴근하고 배고픈 사람을 위한, 15분 안에 끝나는 다섯 가지 한 그릇 요리.

| 레시피 | 종류 | 분량 | 난이도 |
|---|---|---|---|
| [15분 마늘버터 새우 파스타](15분-마늘버터-새우파스타.md) | 파스타 | 2인분 | 쉬움 |
| [15분 들기름 막국수](15분-들기름-막국수.md) | 면 (차가운) | 2인분 | 아주 쉬움 |
| [15분 에그인헬](15분-에그인헬.md) | 원팬 / 빵 | 2인분 | 쉬움 |
| [15분 간장버터 대패덮밥](15분-간장버터-대패덮밥.md) | 덮밥 | 2인분 | 아주 쉬움 |
| [15분 캐러멜 바나나 프렌치토스트](15분-캐러멜-바나나-프렌치토스트.md) | 디저트 | 2인분 | 쉬움 |

## 공통 구성

각 레시피는 같은 형식을 따릅니다.

- **재료** — 파트별로 나눠 정리
- **만드는 법** — 단계마다 경과 시간 표기 (0분 → 15분)
- **성공 포인트** — 왜 그렇게 해야 하는지 이유까지
- **응용** — 매운맛, 비건, 재료 대체 등
- **곁들이면 좋은 것**
