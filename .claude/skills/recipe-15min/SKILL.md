# 15분 레시피북 작성기

레시피 한 편을 **글 + 썸네일 + 목차 갱신**까지 한 번에 끝낸다. 산출물은 `week-1/quests/레시피북/`에 쌓이는 시리즈이므로, 글 형식과 그림 화풍이 기존 편들과 **똑같이** 맞아야 한다.

## 산출물

레시피 한 편당 파일 3개가 움직인다.

| 파일 | 내용 |
|---|---|
| `week-1/quests/레시피북/<N>분-<요리이름>.md` | 레시피 본문 (한글 파일명) |
| `week-1/quests/레시피북/<ascii-slug>.jpg` | 썸네일 (**ASCII 파일명** — 마크다운 이미지 링크가 깨지지 않게) |
| `week-1/quests/레시피북/README.md` | 목차 표에 한 줄 추가 |

## 작업 순서

### 1. 메뉴 정하기

사용자가 종류만 말하면(예: "디저트") 직접 고른다. 고를 때 기준:

- **기존 편과 종류가 겹치지 않을 것.** 먼저 `README.md` 목차를 읽어 이미 있는 종류(파스타/면/원팬/덮밥/디저트…)를 확인한다.
- **정말 그 시간 안에 되는 요리.** 물 끓이는 시간, 해동, 냉장 굳히기까지 포함해서 계산한다. 30분 걸리는 요리를 15분이라 쓰지 않는다.
- **집에 있을 법한 재료.** 특수 재료는 "선택"으로 표시하거나 대체재를 적는다.

고른 이유를 한 줄로 사용자에게 말한다.

### 2. 본문 쓰기

[references/recipe-template.md](references/recipe-template.md)의 구조를 그대로 따른다. 섹션 순서·제목·표 형식을 임의로 바꾸지 않는다.

글을 쓸 때 지킬 것:

- **단계마다 경과 시간을 표기한다** (`(0분)` → `(15분)`). 마지막 단계의 시간이 제목의 총 시간과 정확히 맞아야 한다.
- **각 단계에서 결정적인 디테일 하나를 굵게** 강조한다. 예: **면수 한 국자는 반드시 따로 덜어 두세요**, **첫 1분은 건드리지 않기**.
- **"성공 포인트" 표는 이유까지 쓴다.** "면수를 남기세요"가 아니라 "전분이 버터와 물을 이어 주는 유화제 역할을 한다"까지. 그 요리에서 **실제로 실패하는 지점**을 골라야 한다 — 일반론을 채워 넣지 않는다.
- **응용은 4개**, 방향을 다르게: 매운맛 / 크리미 / 재료 추가 / 대체(비건·다른 단백질).
- 어투는 담백한 존댓말. 이모지, 느낌표 남발, "정말 맛있어요" 같은 빈 감탄은 쓰지 않는다.

### 3. 썸네일 생성

`GEMINI_API_KEY`가 필요하다. `.claude/settings.local.json`의 `env`에 들어 있다(git에 올라가지 않음). 없다고 나오면 사용자에게 키를 요청한다.

```bash
python .claude/skills/recipe-15min/scripts/gen_thumbnail.py \
  --out "week-1/quests/레시피북/<ascii-slug>.jpg" \
  --subject "<장면 묘사 — 아래 규칙 참고>"
```

여러 장을 한 번에 만들 때는 `--out`/`--subject` 쌍을 반복하면 병렬로 돈다.

```bash
python .claude/skills/recipe-15min/scripts/gen_thumbnail.py \
  --out "a.jpg" --subject "..." \
  --out "b.jpg" --subject "..."
```

**장면 묘사(`--subject`)를 쓰는 규칙:**

- 화풍은 스크립트의 잠긴 `STYLE` 블록이 붙여 준다. **묘사에는 화풍을 다시 쓰지 말고 장면만** 쓴다.
- 첫 문장은 `<요리 이름>, viewed from a slight three-quarter angle on a <표면>` 형태로 구도를 고정한다.
- **레시피에 실제로 들어간 재료를 그대로 나열한다.** 편 썬 마늘, 페페론치노, 노른자, 페타 치즈 같은 것들. 일반적인 "pasta dish"라고 쓰면 레시피와 따로 노는 그림이 나온다.
- 배경에 소품 2~3개를 흐리게 배치한다 — 그 요리에 쓴 도구(무쇠팬, 기름병)나 "곁들이면 좋은 것"에 적은 것(커피, 동치미). 글과 그림이 연결된다.
- 그릇 색, 김, 소스 광택, 빛의 방향 등 질감을 구체적으로 적는다.
- 영어로 쓴다.

생성 후 **반드시 Read 도구로 이미지를 열어 확인한다.** 재료가 빠졌거나 화풍이 튀면 묘사를 고쳐 다시 생성한다.

> 응답 MIME은 JPEG다. 출력 파일 확장자는 `.jpg`로 쓴다.

### 4. 목차 갱신

`README.md` 표에 행을 추가하고, 첫 문단의 개수 표현("네 가지" → "다섯 가지")도 함께 고친다.

```
| [<제목>](<한글파일명>.md) | <종류> | <N>인분 | <난이도> |
```

### 5. 보고

사용자에게: 고른 메뉴와 그 이유, 겹치지 않게 잡은 종류, 썸네일에 반영한 요소, 갱신한 파일 목록.

## 함정

- **이미지 파일명에 한글을 쓰지 말 것.** 마크다운 링크와 일부 뷰어에서 깨진다. 본문 `.md`는 한글이어도 된다.
- **`STYLE` 블록을 건드리지 말 것.** 한 글자만 바꿔도 새 그림이 기존 편들과 톤이 어긋난다. 시리즈 전체를 다시 뽑을 게 아니면 그대로 둔다.
- **이미지 링크는 상대 경로**로. `.md`와 `.jpg`가 같은 폴더에 있으므로 파일명만 쓴다.
- 새 시리즈를 다른 폴더에 시작하는 경우가 아니면, 파일을 `week-1/quests/레시피북/` 밖에 만들지 않는다.
